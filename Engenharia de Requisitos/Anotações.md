Requirements Elicitation(Eliciação de Requisitos) - Encontrar os problemas e descobrindo as necessidades de usuário, problemas de negócio e limites de sistema.

Requirements Analysis - Produzir soluções para cada necessidade que verifiquei.

Requirements Specification - Documentação dos requisitos.

Requirements Validation - Verificar se estamos fazendo o sistema corretamente.

Iterative Nature of The Requirements Process - O processo de requisitos é iterativo e linear, possuí mudança constante cujo objetivo é apresentar uma solução computacional.
