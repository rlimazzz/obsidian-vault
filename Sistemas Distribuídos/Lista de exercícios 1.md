1) Memória ram, armazenamento, processamento, memória em disco, processamento de vídeo. 
2) Em um servidor único a abordagem é mais fácil de administrar por se tratar de apenas um servidor(não necessitar de sincronização), entretanto essa abordagem não é tão a prova de falhas pois se der algum problema em toda rede local o servidor também ficará offline. Pode ser resolvido com a ajuda de outro servidor backup em outra localização, quando o principal está offline o backup entra em ativa substituindo o principal.
3) O modelo cliente-servidor é guiado a respostas de cada um dos lados, o cliente envia uma requisição ao servidor e assim recebe uma resposta. Na computação em nuvem os recursos são fornecidos como serviço pela internet por um provedor (AWS, GCP, Azure), e assim são contratados e distribuídos em várias regiões do mundo, sendo pagos apenas pelo uso.
4) O uso de HTML, URLs e HTTP serve como um apoio para transmitir mensagens do cliente para o servido,  caso o cliente precise de determinado serviço ele pode fazer uma requisição HTTP à uma API que irá chamar o servidor para disponibilizar tal recurso para o cliente.
